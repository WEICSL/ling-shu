📌 项目简介

灵枢是一款集成本地Ollama模型和云端DeepSeek API的智能对话平台。
支持多会话管理、Agent工具调用、人设定制等功能，提供流畅的AI对话体验。

🛠️ 技术栈

Django 6.0 Ollama DeepSeek API SQLite Live2D Marked.js Highlight.js

✨ 核心功能

  • 💬 多会话对话管理
  • 🤖 Agent模式（工具调用）
  • 🎭 可定制AI人设
  • 🎨 Markdown渲染 + 代码高亮
  • 🖱️ 右键复制/删除消息
  • 📱 响应式界面设计
